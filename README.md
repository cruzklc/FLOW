# FLOW

FLOW is a voice-first thought-capture tool built for a CEO and their right hand. Speak or type whatever's on your mind, and Claude automatically sorts it into the right category and priority — turning scattered thoughts into an organized, shared dashboard you can both work from.

## What it does

- **Capture by voice or text** — tap the mic and talk, or type it out
- **AI categorization** — Claude reads each capture and tags it with a category (Action Item, Decision Needed, Idea, FYI, Urgent) and a priority level
- **Multi-thought splitting** — ramble about five different things in one breath, and FLOW automatically splits them into five separate items
- **Shared dashboard** — Kanban and List views to track everything by status, with a health bar showing overall progress at a glance
- **Inbox messaging** — comment threads on individual items so notes don't get lost
- **Bulk actions** — select multiple items to change status, archive, or delete all at once
- **Color themes** — pick a personal color theme that's saved to your account and follows you across devices
- **Login digest** — a quick summary of what's new and what needs attention, shown right when you log in

## Tech stack

- **Frontend:** Vanilla HTML, CSS, and JavaScript — no framework
- **Backend:** Node.js serverless functions, deployed on Vercel
- **Database:** Postgres, hosted on Neon
- **AI:** Claude (Anthropic API) for categorization and thought-splitting
